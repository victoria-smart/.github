# Victoria - SMART and a Surface Map for a Disk You Can Still Read

## At a Glance

Victoria shows the model, the firmware, and the counters the drive reports, then optionally reads the surface and colors blocks by time. Pending and reallocated sectors are the counters people regret ignoring. A field of slow blocks is the same kind of news even when a single attribute has not flipped yet. The tool does not heal media by scanning it.

- Identity so you test the disk you think you selected
- SMART before any long read
- A surface map only after important files are copied
- USB results treated as suspect until a direct port agrees
- No wipe and no "repair" that overwrites your data as a casual button

1. If the disk already clicks or stalls, copy data before you test.
2. Select the physical drive and read the model.
3. Read SMART. If it is already failing, stop and replace the disk.
4. Run a surface read only when you can leave the machine awake.
5. Retire a drive with growing pending sectors or a bad map.

## Fits

Benches and careful home checks of a hard disk or an SSD the firmware will talk to. A poor fit for file recovery from a drive that no longer enumerates. A poor fit for wiping a disk you intend to sell. A poor fit for a USB dock that hides errors. Move the drive to a direct connection before you trust a perfect report.

## Fixes

The wrong disk was selected. Stop. Identity is the first screen.
SMART is blank on USB. The bridge is hiding it.
The map is slow everywhere on a dock. Retest on SATA.
The PC froze. The disk is bad enough to stall Windows. Boot elsewhere and copy what you can.
You wanted to repair bad blocks. Replace the drive. A remap is not a promise.

## Copy Files Before You Map a Sick Disk

Victoria's surface grid is a diagnosis. If SMART already shows pending or reallocated sectors, or the drive already stalls, copy the files that matter before you start a long read. The map will not extract a document from a sector that is about to die, and the test itself is a heavy read. A USB dock that makes every block look slow should be replaced with a direct SATA connection before you condemn the disk. Identity comes first so you do not scan the healthy system drive for an hour.

| Result | Next step |
|---|---|
| SMART already failing | Copy, then replace |
| Slow map only on USB | Retest on a direct port |
| Quiet SMART and a clean map | Look at cables, RAM, or the filesystem |
| Wrong model on screen | Stop immediately |

A remap is not a repair you schedule every month. A drive that needed one is a drive you stop trusting with the only copy of anything.

## Identity, SMART, Then Maybe the Map

Read the model before a surface test so you do not scan the wrong disk for hours. If SMART already shows pending or reallocated growth, copy the files and replace the drive. The map will not extract a document from a dying sector, and the test is a heavy read. Use the map when health is uncertain and the copies still stall. A USB dock that paints every block slow should be replaced with a direct connection before you condemn the drive.

There is no monthly repair pass. A drive that needed remaps is a drive you stop trusting with the only copy of anything. Leave the PC awake for a long read. If Windows freezes, the disk is bad enough to stall the system. Boot elsewhere and copy what you can.

- Correct physical disk
- SMART before the surface
- Files copied if the drive already hesitates
- USB results confirmed on SATA
- Long tests not looped on a confessing disk
- Sleep disabled
- Replacement planned when the map is full of delays

| Result | Action |
|---|---|
| SMART failing | Copy, stop testing |
| Slow only on USB | Retest direct |
| Bad blocks | Replace |
| Quiet result | Look at cables or RAM if the PC still stalls |

Write down the model and the bad counter. The grid is the note.
